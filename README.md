# together-time
CCAI9013 Group Project

**Together Time** is a web prototype that helps children aged 6–8 balance screen time with offline activities and family connection.

**Live site:** https://ravxraptor.github.io/together-time/

## What's in the prototype
- **Parent space:** activity library, screen-time calendar and plans, simulated app locks, activity goals, photo reviews with an AI check, family linking.
- **Child space:** today's plan, "Give me an idea" activity suggestions, photo submissions, progress and an interests profile.
- English, Cantonese and Mandarin, with read-aloud audio.

AI features use Chrome's built-in on-device model when it is available, so no names or photos leave the device. Screen locks and family linking are simulated for the demo.
